
# 📄 [게임 소개 및 실행 설명서] Fan Passport (팬 패스포트)

**App Category:** Web3/Web2.5 기반 팬덤 게이미피케이션 & 피지털(Phygital) 컬렉션 게임

**Platform:** Cross-Platform WebApp (PC/Mobile 브라우저 지원)

---

## 1. 게임 개요 (Game Overview)

### "덕질이 게임이 된다! 나만의 팬덤 패스포트를 완성하라!"

**Fan Passport**는 BTS, 블랙핑크 등 여러 플랫폼으로 파편화되어 있던 덕질 이력을 하나로 통합하고, 팬 활동을 **게임의 퀘스트와 카드 수집/합성 요소**로 재해석한 **팬덤 게이미피케이션 플랫폼**입니다.

* **핵심 콘셉트:**
* **마스코트 페르소나:** 나의 덕질 성향에 맞춰 에겐남(감성·총공형 🐰)과 **테토녀(경쟁·직관형 🐯)** 중 마스코트를 선택하고 특화 버프를 받습니다.
* **스마트 컨트랙트 안심 거래:** 2차 리셀 마켓에 +10% 가격 상한선(Anti-Scalping)을 적용하여 암표상과 사기를 기술적으로 원천 차단합니다.
* **듀얼 자산 보상 시스템:** 팬 활동 점수인 `$XP`로 팬 레벨을 올리고, 유틸리티 토큰인 `$FAN`을 사용해 희귀 VIP 선예매 패스(SSR)를 뽑거나 재판매 마켓에서 안전하게 거래합니다.



---

## 2. 플레이 방법 (How to Play)

```
[1. 캐릭터 선택] ──> [2. 일일 퀘스트 수행] ──> [3. 토큰 소각 & 카드 합성] ──> [4. 리셀 마켓 거래]
  - 에겐남 (🐰)         - 스트리밍 인증        - $FAN 소각 (Burn)              - 상한선 내 안전 거래
  - 테토녀 (🐯)         - GPS 직관 인증         - SSR VIP 패스 획득             - 소유권 즉시 이전

```

### 1단계: 마스코트 캐릭터 선택 (페르소나 설정)

* 앱 시작 시 본인의 덕질 스타일을 결정하는 마스코트를 선택합니다.
* **에겐남 (🐰):** 음원 스트리밍 및 총공 퀘스트 수행 시 **+20% 추가 보상**
* **테토녀 (🐯):** 현장 출석 및 리셀 마켓 티켓 합성 성공 시 **+15% 확률 버프**



### 2단계: 일일 덕질 퀘스트 (포인트 & 토큰 수급)

* **[마이 패스]** 탭에서 '일일 덕질 퀘스트'를 진행합니다.
* 스포티파이/멜론 음원 총공 인증 버튼을 누르면 `+$XP`(활동 점수)와 `+$FAN`(유틸리티 토큰)이 즉시 적립됩니다.
* 보유 토큰이 부족할 경우 **[토큰 상점]** 탭으로 이동하여 PG 원화 결제로 추가 충전할 수 있습니다.

### 3단계: 토큰 소각(Burn) 및 SSR 카드 합성

* 보유한 `$FAN` 토큰 40개를 소각(Burn)하여 **SSR 등급의 VIP 선예매 패스/한정판 포카**를 합성(뽑기)합니다.
* 뽑은 소유권 카드는 내 '스마트 보관함'에 온체인 위변조 방지 상태로 영구 보관됩니다.

### 4단계: 암표 없는 2차 리셀 마켓 이용

* **[리셀 마켓]** 탭에서 스마트 컨트랙트로 보호받는 2차 매물을 안전하게 거래할 수 있습니다.
* 모든 거래는 **정가 대비 최대 +10% 상한선**이 고정되어 있어 암표 폭리 염려 없이 안전하게 소유권을 P2P 이전받을 수 있습니다.

## 3. 실행 방법 (How to Run)

본 앱은 별도의 복잡한 개발 환경 구축(Node.js, npm, 빌드 과정 등)이 필요 없는 Single-File WebApp(개념 검증 PoC 모델)으로 제공됩니다.

### 💡 방법 A: 로컬 컴퓨터에서 즉시 실행 (가장 추천)

1. 이전 단계에서 작성된 완성형 **`index.html`** 코드를 복사합니다.
2. 컴퓨터 바탕화면에 메모장(Notepad)이나 VS Code를 열고 코드를 붙여넣은 뒤, 파일 이름을 `index.html`로 저장합니다.
3. 저장된 **`index.html`** 파일을 더블클릭하면 크롬(Chrome), 사파리(Safari), 웨일(Whale) 등 모든 브라우저에서 즉시 데모 게임이 실행됩니다.
